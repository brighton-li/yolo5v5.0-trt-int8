纯 GPU = 输入常驻显存、CUDA Event 夹住一次网络执行

端到端 = 解码 + 前处理 + 推理 + 解码/NMS

推理 = H2D 输入拷贝 + 网络计算 + 流同步 + D2H 输出拷贝

后处理 = v5.0 解码（raw logits→sigmoid→grid/anchor→cxcywh）+ NMS。

流水线 = 前处理 + 推理 + 后处理（不含解码）

名义占用 = 纯 GPU 时间 / 端到端时间。**名义占用 越闲、越容易被降频**。

训练卡GPU计算太快，长期空闲，导致250帧以后降频，单帧耗时更长
